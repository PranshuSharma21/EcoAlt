Overview & PhilosophyQuick-commerce apps deliver groceries in 8 minutes, but that convenience hides two major problems:Silent Default Waste: Checkout flows automatically bundle single-use liners, disposable cutlery, and extra carry bags that rushed buyers never asked for.The Disposables Tax: Single-use items (paper towel rolls, throwaway alkaline batteries, plastic party plates, small rigid bottles) are pushed first because repeat purchases drive margin—costing households up to 4× more over a few months.Our Rule — The Dual-Benefit Filter:
EcoAlt never shows a swap unless both conditions are met:💰 The Customer Wins: You save money upfront (e.g., concentrated refills) or save significantly over the product's lifespan (e.g., washable bamboo cloths, USB-C rechargeable batteries).🌱 The Planet Wins: Single-use plastic packaging, landfill waste, or delivery emissions are measurably reduced.📱 2. Product-Aware Checkout LogicUnlike generic checkout screens that ask "Do you want plastic cutlery?" when you only bought milk, EcoAlt inspects the ecoGroup of items in your cart and renders only relatable choices:🥛 When Dairy & Bread (Amul Milk, Sandwich Bread) are in Cart:Skip extra plastic pouch liner (+15 GP)Hand back rinsed empty milk/bread pouches to delivery rider for LDPE recycling (+20 GP)🥔 When Snacks, Drinks & Tableware (Lay's, Maggi, Coca-Cola, Plates) are in Cart:Skip disposable cutlery & paper napkins (+15 GP)🧴 When Home & Personal Care (Vim, Dettol, AA Batteries, Toothbrush) are in Cart:Return old empty bottle or used battery cells to rider (+25 GP)🛍️ Universal Outer Packaging Choice:Minimal (No Bag) — Instant ₹5 off bill + 20 GP vs. Standard Bag📂 6. Project File StructureThe entire application is built in 3 clean, comment-free files with zero external framework dependencies:index.html — Centered iPhone 15 Pro viewport, Figma splash screen, status bar with WiFi & battery icons, 3-tab Blinkit interface (Store, Cart, Green Points), and desktop margin typography (EcoAlt / Know before you click).style.css — Responsive styling, Blinkit 2-column product tile grid, custom EcoAlt ON/OFF toggle switch, and smooth modal/toast transitions.script.js — Product catalog data, dual-benefit swap engine, dynamic cart choice generator, Green Points wallet math, and localStorage persistence.🛠️ 7. Local Setup & DeploymentBecause EcoAlt uses browser localStorage to persist your cart, swaps, and Green Points balance, no backend server or database is required.Clone the repository:git clone https://github.com/your-username/ecoalt.git
cd ecoalt
Run locally:
Open index.html directly in any modern browser, or start a local static server:npx serve .
Deploy on GitHub Pages:
Push index.html, style.css, and script.js to your main branch, open Settings → Pages, select Deploy from a branch (main / root), and your live app is ready!📈 8.
