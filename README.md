## ⚡ The Problem

Quick-commerce platforms deliver essentials in under 10 minutes, but this frictionless convenience hides a major systemic trap:

- **Silent Waste Injection:** Default checkout flows automatically bundle single-use plastic cutlery, moisture-barrier poly-liners, and extra carry bags that rushed shoppers never asked for.
- **The Planned Obsolescence Tax:** Dark stores prioritize high-margin, short-lived disposables (like single-use batteries, paper towels, and rigid plastic bottles), costing households up to **4× more** in recurring monthly re-buys.
- **Zero Real-Time Visibility:** At the moment of the click, users only see speed and convenience. The environmental footprint and recurring financial drain remain completely invisible.

---

## 🌐 Our Solution

Think of **EcoAlt** as an intelligent, real-time decision co-pilot embedded directly into the quick-commerce experience.

EcoAlt operates under a strict **Dual-Benefit Filter**: it never guilt-trips users, and it **only** nudges them toward an alternative when switching satisfies both criteria:

1. 💰 **The Customer Wins:** Lower upfront cost (e.g. concentrated refills) or significant long-term savings over the product lifespan (e.g. washable bamboo cloths, rechargeable USB-C cells).
2. 🌱 **The Planet Wins:** Single-use plastic diverted from landfills, reduced secondary packaging, and lower transport emissions.

> **The Honest Restraint Rule:** If an item is already optimal (like recyclable milk pouches vs. heavy glass bottles), EcoAlt respects it and pushes zero artificial swaps.

## 🏗️ Technical Architecture

| Layer | Technologies Used | Description |
| :--- | :--- | :--- |
| **Client Hook & Intercept** | `Vanilla JavaScript`, `DOM Observers` | Intercepts product SKU metadata, material composition tags, and category flags upon view render. |
| **Dual-Benefit Evaluation Engine** | `Pure JS Logic`, `Constraint Solver` | Evaluates durability multipliers, unit pricing economics, and carbon offset thresholds in real time. |
| **Dynamic UI Injection** | `HTML5`, `CSS3 Grid/Flexbox` | Mounts iconic 2-column Blinkit tiles, inline 1-tap swap strips, the EcoAlt ON/OFF slider, and contextual checkout. |
| **Persistent State Layer** | `Web Storage API (localStorage)` | Manages zero-backend state across cart contents, active swaps, Green Points balances, and telemetry history. |
| **Reverse Logistics Pipeline** | `Hyper-Local Dark Store Routing` | Coordinates delivery rider return itineraries to collect clean LDPE milk pouches, paper bags, and battery cells. |

## ⚙️ How It Works

1. **Catalog Browsing:** The user navigates the 2-column Blinkit storefront. If EcoAlt mode is `ON`, eligible items display inline swap banners with exact cost-per-use math.
2. **One-Tap Upgrade:** Tapping `⚡ Swap` replaces the disposable product in the cart, automatically crediting Green Points and calculating lifetime savings.
3. **Contextual Checkout Inspection:** When the user opens the cart, EcoAlt checks the categories present and populates relevant conscious choices (e.g., skip poly-liner, return empty bottles).
4. **Loyalty Loop & Settlement:** The user redeems earned Green Points for an instant bill discount or free reusable essentials, checking out in 8 minutes with zero friction.
